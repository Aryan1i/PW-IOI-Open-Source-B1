# PW IOI – Open Source B1

A collection of learning resources, practice materials, revision notes, and session-wise content from **PW Institute of Innovation (PW IOI)**.

This repository is intended to help students revise concepts, organize learning materials, and collaborate through GitHub.

## 📚 Repository Structure

```text
PW-IOI-Open-Source-B1/
│
├── Javascript Revision/
│   └── JavaScript learning and revision materials
│
├── Session - Git & Github Revision/
│   └── Git and GitHub session notes and practice
│
└── README.md
```

## 📖 Topics Covered

### 1. JavaScript Revision
- JavaScript fundamentals
- Variables and data types
- Operators and expressions
- Conditional statements
- Loops and functions
- Arrays and objects
- Practice questions and revision

### 2. Git & GitHub Revision
- Introduction to Git and GitHub
- Git installation and configuration
- Repository creation
- Basic Git commands
- Adding and committing changes
- Branching and merging
- Push and pull operations
- Collaboration and version control

## 🎯 Objectives

- Maintain organized academic resources.
- Revise important programming concepts.
- Practice software development tools.
- Learn version control and collaboration.
- Encourage open-source contributions among students.

## 🛠️ Technologies & Tools

- JavaScript
- Git
- GitHub
- Visual Studio Code

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Aryan1i/PW-IOI-Open-Source-B1.git
```

Navigate to the project directory:

```bash
cd PW-IOI-Open-Source-B1
```

Explore the folders and access the available learning materials.
